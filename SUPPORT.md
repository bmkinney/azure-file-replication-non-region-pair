# Support

This is a community project, provided under the [Apache License 2.0](LICENSE) without warranty or a service-level agreement.

- **Questions and bugs:** open an [issue](https://github.com/bmkinney/azure-file-replication-non-region-pair/issues/new/choose). Include the deployment method, the command you ran, and the error, with subscription, tenant, and resource IDs replaced by placeholders.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md). Don't open a public issue.
- **Azure service problems:** for problems with Azure Files, Azure Container Apps, Azure Container Registry, or Azure Monitor themselves, contact [Azure support](https://azure.microsoft.com/support/create-ticket/) through your own support plan.

Before you open an issue, check the [Troubleshooting](README.md#troubleshooting) section of the README and collect the diagnostics it describes.
